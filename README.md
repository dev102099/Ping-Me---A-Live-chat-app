# 🟢 Ping Me - Real-time Chat App

**Ping Me** is a full-featured real-time chat application built with the **MERN stack** and **Socket.io**. It supports one-on-one messaging, user authentication & authorization, and more! It's designed to be fast, secure, and ready for scalable growth.

---

## 🚀 Tech Stack

- **MongoDB** – Database
- **Express.js** – Backend Framework
- **React.js** – Frontend UI
- **Node.js** – Server
- **Socket.io** – Real-time communication
- **JWT** – Secure user authentication
- **Cookies** – Token handling

---

## ✨ Features

- ✅ **User Authentication**

  - Register & login securely using JWT
  - Passwords are hashed and stored securely

- ✅ **Authorization**

  - Protected routes & user-specific access

- ✅ **One-on-One Chat**

  - Real-time messaging with typing indicators
  - Message history persists in MongoDB

- ✅ **Add/Search Users**

  - Find other users to chat with easily

- ✅ **Real-time Communication**
  - Powered by **Socket.io**
